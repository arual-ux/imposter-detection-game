 🕵️ Imposter Detection Game

A fun, interactive, mobile‑friendly security awareness game designed to help employees recognise impersonation attacks.  
Players must decide whether each scenario is **Real** or an **Imposter**, based on behavioural and technical warning signs.

This game supports the training objectives from the *Impersonation Attack Awareness* presentation.

---

 🎮 How to Play

1. Read each scenario carefully  
2. Look at the avatar (randomised each round)  
3. Decide whether the scenario is **Imposter** or **Real**  
4. Try to score at least **80%** to pass  
5. Review any mistakes at the end to reinforce learning  

---

 ✨ Features

-  100% browser‑based (no installation needed)  
-  Mobile‑responsive design  
-  Randomised avatars  
-  Randomised scenario order  
-  Progress bar  
-  Confetti celebration on pass  
-  Full results page with detailed feedback  
-  Wrong answers listed for revision  
-  Smooth animations and clean UI  
-  Large question bank
